# Tic Tac Toe Game

## Project Overview

This is a HTML, CSS and JavaScript based Tic-tac-toe game that runs in the browser. The project is all about the practice of JavaScript factory functions, module patterns, DOM manipulation and event handling.

The game is played until one player gets all the spaces marked on the 3 x 3 board.

## Features

- Two-player gameplay.
- Interactive 3×3 game board.
- Detects winning combinations.
- Identifies draws where no spaces are available.
- Displays whose turn it is.
- Restart functionality.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Concepts Practiced

- Modules and IIFEs in JavaScript.
- Factory functions.
- Closures and private variables.
- DOM manipulation.
- Event listeners.
- Game logic and conditional statements.

## Getting Started

1. Clone this repository.
2. Open VS Code and open the project folder.
3. Go into your browser and open `index.html`.
4. Start playing!

## What I Learned

This project made me realize that it is possible to structure the code for JavaScript in separate modules, and manage the state of a game without showing any other variables. It also helped me to understand the DOM manipulation and working of JavaScript with HTML and CSS.
